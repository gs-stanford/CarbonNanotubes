# CPT v1: official commercial-fiber benchmark candidates

Research date: 2026-10-01. Seven recommended additions; no database/build edits. These are manufacturer reference values, **not measurements paired on the same specimen, not guaranteed minima, and not newly human-validated experimental records**. Parent review/admission remains required.

## Conditions and source checks

- M46J/M55J: p.1 **fiber** properties, not the adjacent 60%-fiber-volume epoxy-composite table. Mechanical method TY-030B-01; density TY-030B-02. P.2 identifies lot-average reference values and revision 04/22/2025. M46J 6K is 4200 MPa / 1.0%; 12K is 4020 MPa / 0.9%; do not mix these rows. M55J is 6K, untwisted, sizing 50B (1.0%). M46JB 6K 50B identity is also listed in the [European selector](https://toray-cfe.com/en/products/torayca-carbon-fibers/product-selector/). Temperature, humidity and gauge length are not specified in these sheets.
- IM9/IM11: p.1 typical fiber properties; modulus is chord 1000-6000 microstrain (sheet prints `Chord 6000-1000`). No ASTM/ISO mechanical standard, temperature, humidity or gauge length is stated. IM9 is never twisted, 24K, GS 0.5% sizing. IM11 is never twisted; listed 12K packaging uses GP or R 0.9% sizing, but the property table does not distinguish their results. Use one IM11 record, not duplicate 6K and 12K records with identical mechanical values. Printed copyright dates are 2025 and 2026; IM9 p.2 code is `CTA 535 NV25`. Do not infer exact issuance dates from upload directories.
- T1200/M40X: official HTML grade tables, no stated revision date or test method. Direct SI values are used; no maxima assembled across grades. Keep tow/sizing unspecified for these selector-based records. The [2023-10-29 T1200 announcement](https://www.toraypmc.com/newsroom/news-item/2023/10/29/Toray-Develops-TORAYCA%E2%84%A2-T1200%2C-the-Ultra-High_Strength-Carbon-Fiber) identifies 12K but rounds modulus to 46 Msi; do not replace the selector's direct 315 GPa with a conversion of that rounded number.
- Spectra: nominal yarn values, exact S-1000/75 row. Test method, temperature, humidity and gauge length are not reported. This is an archival manufacturer benchmark, not confirmation of current commercial availability. The old `advancedmaterials.honeywell.com` PDF URL redirects to Solstice; the cited manufacturer asset-host URL serves the PDF. No family-wide conductivity or maximum modulus is attached to this row.
- Visual table checks completed in memory for M46J, M55J, IM9, IM11, Spectra and Zylon's existing-grade table; no PDFs or rendered images were written. HTML tables were inspected for T1200/M40X. Web screenshot output did not expose image content through the tool wrapper, so PDF visuals were rendered from the official PDFs with PyMuPDF in memory.

## Parent integration

Use the seven `candidates` in the companion JSON as proposed manufacturer benchmarks only. Retain source dates, table/page locators, reported-vs-derived fields, modulus definition and unreported conditions. `initial_modulus_GPa` is deliberately not emitted because the evidence supports manufacturer tensile/chord modulus, not a uniform initial-modulus measurement. No newly paired-specimen strength/modulus relationship should be inferred. Missing fields stay null. SK78 and unresolved generic-grade repairs are follow-ups, not additional admission candidates.
