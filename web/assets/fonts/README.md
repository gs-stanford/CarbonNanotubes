# Figure export fonts

`Arimo-Regular.ttf` and `Arimo-Bold.ttf` are vendored from the official
[`googlefonts/arimo`](https://github.com/googlefonts/arimo) repository at commit
`4a6255f269916ae7ad3fc2706b0935e7621396b8`.

Arimo is metrically compatible with Arial and is used only for deterministic
server-side PNG rendering. SVG and PDF exports retain the plot's Arial/Helvetica
font declarations. The font files are licensed under the SIL Open Font License
1.1 in `OFL-Arimo.txt`.
